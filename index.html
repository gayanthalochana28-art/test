📊 Google Sheets Tutorial

Connect your Notice Board to a Google Sheet for easy updates.

1
Create a Google Sheet
Go to sheets.google.com and create a new spreadsheet.
2
Set up columns
Create three columns: Timestamp, Message, Active.
Example: 2025-06-15, Welcome to ICT class!, TRUE
3
Add notices
Fill rows with your notices. Set Active to TRUE to show, FALSE to hide.
4
Publish to the web
Click File → Share → Publish to web. Choose CSV format. Copy the URL.
5
Replace the URL in code
In script.js, find const NOTICE_SHEET_URL and paste your URL.
6
Done!
Click Refresh from Sheet in the Notice Board to fetch your data.
